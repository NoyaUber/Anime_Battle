# Uploading the ZIP contents to GitHub from a phone

1. Extract the ZIP using your file manager.
2. In GitHub, create a new repository named `anime-battle-arena`.
3. Open the repository and choose **Add file → Upload files**.
4. Upload the *contents* of the extracted `anime-battle-arena` folder, not the ZIP itself and not an extra nested folder.
5. Commit the files to the main branch.
6. Import that repository into Vercel and deploy it.

For a large number of files, GitHub's web uploader can be inconvenient on mobile. You can instead use GitHub Desktop on a computer, or Git from a terminal.
